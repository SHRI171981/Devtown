# Devtown Data Science and ML Training

## Problem statement

Getting job-ready in data science means moving from theory to practice across a wide stack: Python, databases, numerical computing, data analysis, machine learning and deep learning.

## Solution

The complete work from the Devtown data science and machine learning training programme: every lesson's code and notebooks, practice projects, and the lecture transcripts, kept in one repository in the order of the course.

## Tech stack

Python, SQL (SQLite), NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow and Keras, Jupyter.

## Features

- **Python and OOP**: lambdas, modules, classes, regular expressions
- **Databases**: SQL queries, joins, aggregations and accessing a database from Python
- **NumPy and Pandas**: arrays, linear algebra, dataframes and CRUD operations
- **Data visualisation** with Matplotlib
- **Data analysis projects**: IMDB movie analysis with SQL, scraping FIFA data from the web, and a JSON-based Hangman game
- **Machine learning**: linear, support vector, decision tree and random forest regression; logistic regression, KNN, decision tree and random forest classifiers; K-means clustering; Apriori and ECLAT market basket analysis; cross-validation, each with a project notebook
- **Deep learning**: an ANN for handwritten digit recognition and a CNN for image classification
- Lecture transcripts for every session

## Future steps

## Getting started

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow jupyter
jupyter notebook
```

The folders are numbered in course order. Datasets used by the machine learning notebooks are included in `9. Machine Learning/`.
